# 功能介绍视频 · 拍摄脚本（3 分钟版）

> 目标：让一个没听说过这个模组的人，在 30 秒内明白「它干什么」、在 3 分钟内相信「它做得好」。
> 台词按 4~5 字/秒写，正常语速念完即可，不要赶。

---

## 一、拍摄参数

| 项 | 设置 |
|---|---|
| 录制工具 | OBS Studio（免费） |
| 分辨率/帧率 | **1920×1080 @ 60fps**（建造过程靠帧率才有"生长感"） |
| 编码 | x264，CRF 20~23 |
| 来源 | 窗口采集：游戏窗口一个场景、建造台窗口一个场景，方便切 |
| 音频 | **先录画面、后单独配音**（别边操作边录，鼠标声会全进去） |
| 游戏内准备 | 建议先开 HEROsMod 全亮 + Better Zoom，否则画面黑、看不清 |

## 二、分镜表 + 台词

### 镜头 1｜0:00–0:06　钩子

**画面**：成品像素画全景（Better Zoom 拉到最远，HEROsMod 全亮）。镜头可以缓慢平移一下。

> 这不是手绘的，也不是地图编辑器刷的。
> 这是一张图片，自动变成的。

### 镜头 2｜0:06–0:16　定位

**画面**：切到原图，再切回方块成品，左右分屏对比。

> 这个模组叫泰拉图像建造台。
> 你给它一张图，它帮你算成方块，然后一块一块建进世界里。
> 全程你只需要站着。

### 镜头 3｜0:16–0:40　核心流程（正常速度）

**画面**：建造台操作：选择图片 → 点「生成预览」→ 预览出现 → 点「连接游戏」→ 显示"已连接 · 模组 v1.2.2" → 点「开始建造」。

> 第一步，导入图片。PNG、JPG 都行。
> 第二步，生成预览。这一步会算好每个像素该用哪个方块，不连游戏也能看。
> 第三步，连接游戏，点开始建造。
> 剩下的交给它。

### 镜头 4｜0:40–1:05　建造过程（加速 4~8 倍）

**画面**：游戏内视角，方块一片片长出来。**开头 2 秒和结尾 2 秒用正常速度**，中间加速。建议叠加一个"已放置 / 总数"的小字。

> 每秒大概能放两千块，二十万块也就三十多秒。
> 中途可以随时按 P 暂停，按 U 全部撤销。

### 镜头 5｜1:05–1:30　三个开关（关键卖点）

**画面**：切到渐变色块对比 —— 同时展示"抖动关"和"抖动开"两段（用 `output/workshop/shot2_dither.png` 的逻辑，现场在软件里切开关再生成更真实）。再顺手切一次「优先保色相」的人像效果。

> 三个可选开关，默认全关，不影响原本的手感。
> 这个叫抖动，处理渐变，开了以后色块断层就没了。
> 这个是优先保色相，专门治"红变棕、蓝变紫"，画人物的时候开它。

### 镜头 6｜1:30–1:50　自定义色卡

**画面**：打开色卡面板 → 在原图上点一下取色 → 选方块 → 添加 → 生成预览，指出那块颜色被修正了。

> 如果某个区域怎么调都不满意，可以直接指定。
> 在这个图上点一下取色，选一个方块，加进去。
> 最多能存五十条，跟着工程文件一起保存。

### 镜头 7｜1:50–2:05　其它实用功能

**画面**：快速切几个界面：预处理（裁剪/旋转/亮度）、导出工程、断点续传提示。

> 还有裁剪、旋转、亮度对比度，自动缩放到你想要的大小。
> 工程可以存下来，下次直接接着建。
> 中途断线了也不怕，重连之后只补没建完的部分。

### 镜头 8｜2:05–2:25　搭配推荐（必须讲）

**画面**：先关掉 HEROsMod 全亮 → 画面明显发黑（对比）→ 再打开 → 亮起来。然后 Better Zoom 拉一个远景。

> 最后说个很重要的事。
> 这个模组只负责放方块，不管灯光也不管镜头。
> 所以强烈建议同时装 [HEROsMod] 和 [Better Zoom]。
> 不开全亮的话，建出来的东西中间是黑的，你自己都看不清建了啥。

### 镜头 9｜2:25–2:40　收尾

**画面**：成品远景 + 屏幕文字：模组名 + 工坊搜索关键词 + 桌面端下载地址。

> 创意工坊搜索"泰拉图像建造台"就能找到，免费订阅。
> 桌面端程序在工坊页面的描述里，链接直接点。
> 下一期我会拿它复刻几个经典画面，感兴趣可以先订阅。

## 三、配音与字幕

1. **先录画面**，按上面的分镜拍完，剪辑软件里按镜头切开
2. **照台词念**，手机或任意录音软件单独录，一段一条，录错了单独重念那一段（不要一气录完）
3. **字幕三条路**：
   - 最省事：剪映 / CapCut → 导入音频 → 自动识别字幕 → 改错别字
   - 想精确：`pip install faster-whisper` → 转出 SRT → 拖进剪辑软件
   - 想统一风格：Remotion（用 React 写视频，字幕是一个数组，改一行就重渲染）

**字幕规范**：一行 ≤ 18 个汉字，最多两行；专有名词统一（HEROsMod / Better Zoom / CIEDE2000）。

## 四、封面 / 缩略图

三选一：

1. **直接截成品**：像素画全景 + 大标题文字（最真实，观众一眼知道是游戏内容）
2. **左右对比**：原图 vs 方块画（信息量最大，转化率通常最好）
3. **本地模型生成**：`python D:\deepseek\ds_gen.py image --prompt "..." --width 1024 --height 576`（Qwen-Image，做氛围图可以，但注意别做出和游戏无关的插画）

我的建议是 **2**：左右对比最能说明"这是一张图变的"。
