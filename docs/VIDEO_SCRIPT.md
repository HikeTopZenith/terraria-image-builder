# 功能介绍视频 · 拍摄脚本 v2

> 两版都写好了：**A · 30 秒竖屏短片**（抖音/小红书）、**B · 3 分钟横屏完整版**（B站/YouTube）。
> 台词里的 `/` 是停顿，`【 】` 是重音，按 4~5 字/秒正常念，不要赶。

---

## 零、先决定发哪里（决定怎么拍，不是小差别）

| 平台 | 时长 | 画幅 | 特点 | 主要靠什么留住人 |
|---|---|---|---|---|
| 抖音 / 小红书 | 30~60 秒 | **竖屏 9:16** | 前 3 秒定生死，全程要"爽点"密集 | 建造"长出来"的画面 |
| B站 / YouTube | 3~5 分钟 | 横屏 16:9 | 观众愿意看细节，会看评论区 | 讲清"为什么它比别人准" |

**建议先拍 B**（素材齐全后再剪 A）。B 的素材可以切片成 A，反过来不行。

## 一、录制前准备（逐项打勾，缺一项就得重录）

**游戏内**

- [ ] 找一个**平坦、背景干净**的建造场地（天空岛或平地都行，别在杂乱的丛林里）
- [ ] 装好 **HEROsMod** 并开启全亮 —— 不开的话画面中间一团黑，全废
- [ ] 装好 **Better Zoom** 并调好一个能看全整幅画的远景档位
- [ ] 材料备足（演示用 42 种方块里挑 8~10 种常用的，每种几百个就够）
- [ ] **关掉聊天栏自动滚动** / 清空聊天记录（否则会录到刷屏）
- [ ] 存档备份一份（录制中建歪了可以回滚重来）

**建造台**

- [ ] 准备好 **2~3 张演示图**（选择标准见下一节）
- [ ] 预先调好参数，录制时只做"点按钮"的动作，不要在现场调滑块（会很拖沓）
- [ ] 「已连接 · 模组 v1.2.2」这个状态要提前连上
- [ ] 把窗口拉到 1920×1080 能完整显示（别让按钮被截掉）

**OBS**

- [ ] 两个场景：`建造台`（窗口采集）+ `游戏`（窗口采集）
- [ ] 输出 1080p **60fps**，x264 CRF 20~23（60fps 是建造"生长感"的命门，30fps 会一顿一顿）
- [ ] 快捷键绑定：开始/停止录制、场景切换（录制时不要用鼠标点 OBS）

## 二、演示图怎么选（这一节最影响成片效果）

**选图三原则**：

1. **尺寸小**：≤ 200×200 像素。一张 1000px 的图缩到 2 万方块也是糊的，而且录制时间翻十倍
2. **色块清晰、对比强**：动漫立绘那种细腻渐变，方块化后一片糊；LOGO、表情包、8-bit 游戏画面、纯色海报效果最好
3. **有辨识度**：观众能一眼认出"这是某某"，惊喜感才成立

**推荐试这三类**（按效果排序）：

| 类型 | 例子 | 为什么好 |
|---|---|---|
| 像素风游戏素材 | 星露谷人物、宝可梦精灵、马里奥砖块 | 本身就是像素，方块化后几乎无损，最惊艳 |
| LOGO / 图标 | 你喜欢的游戏 LOGO、队徽 | 色块规整，远看极清晰 |
| 表情包 | 熊猫头、doge | 观众熟悉，笑点即卖点 |

⚠️ **不要用**：真人照片（模糊）、大尺寸插画（糊+慢）、纯白底图（原版没有亮白方块，会灰）

## 三、A 版：30 秒竖屏短片（抖音 / 小红书）

竖屏构图：**建造台在上、游戏画面在下**，或全程只拍游戏内（更抓人）。

| 时间 | 画面 | 台词（可直接念） |
|---|---|---|
| 0:00–0:03 | 成品像素画全景，镜头缓慢平移。**屏幕大字**：`一张图 = 一面墙` | 【一张图片】，/ 变成泰拉瑞亚里的像素画。 |
| 0:03–0:08 | 切原图，再切回方块成品（硬切，制造对比） | 不是手绘，/ 也不是地图编辑器刷的。 |
| 0:08–0:16 | 建造台：点生成预览 → 点开始建造 → 切游戏画面，方块开始长（**加速 4×**） | 导入，/ 生成预览，/ 点开始。剩下的它自己干。 |
| 0:16–0:24 | 游戏内快进建成，最后 2 秒恢复正常速，镜头拉远看全景 | 【每秒两千块】，/ 二十万块也就半分钟。 |
| 0:24–0:30 | 屏幕文字：`创意工坊：泰拉图像建造台` | 创意工坊搜【泰拉图像建造台】，/ 免费。 |

**竖屏要点**：

- 主体（正在长的墙）要占屏幕**中央 60%**，别贴着边
- 字幕放**上方 1/3**，别放底部（会被抖音 UI 挡住）
- 全程**不要出现鼠标指针乱飞**，剪辑时可以裁掉

## 四、B 版：3 分钟横屏完整版（B站 / YouTube）

### 镜头 1｜0:00–0:06　钩子

**画面**：成品全景（Better Zoom 拉到最远 + HEROsMod 全亮），缓慢平移。屏幕左下角小字：`原图 → 方块画`。

> 这不是手绘的，/ 也不是用地图编辑器一块块刷的。
> 【这是一张图片】，/ 自动变成的。

### 镜头 2｜0:06–0:18　定位

**画面**：左右分屏 —— 左边原图，右边方块成品，同步缓慢平移（观众自己会对比）。

> 这个模组叫【泰拉图像建造台】。
> 你给它一张图，/ 它帮你算好每个像素该用哪个方块，/ 然后一块一块建进世界里。
> 全程你只需要【站着】。

### 镜头 3｜0:18–0:45　核心流程（正常速度，全程不解说卡顿）

**画面**：建造台操作四连击 —— 选择图片 → 生成预览（停顿 2 秒让观众看预览）→ 连接游戏（特写"已连接 · 模组 v1.2.2"）→ 开始建造。

> 第一步，导入图片。/ PNG、JPG 都行。
> 第二步，生成预览。/ 注意 —— 这一步【不连游戏也能看】，/ 它会算好每个像素用哪个方块。
> 觉得可以了，/ 连接游戏，/ 点开始建造。
> 剩下的，/ 交给它。

### 镜头 4｜0:45–1:10　建造过程（4~8 倍速，首尾各 2 秒正常速）

**画面**：游戏内视角。**叠加一个小角标**：`已放置 12,340 / 123,900`。这比干看画面有信息量。

> 每秒大概两千块，/ 十二万块不到一分钟。
> 中途可以按【P】暂停，/ 按【U】全部撤销。
> 断线了也不怕，/ 重连之后只补没建完的部分，/ 不用从头再来。

### 镜头 5｜1:10–1:35　三个开关（核心卖点，必须有前后对比）

**画面**：现场切换。先「抖动关」生成一次预览 → 再「抖动开」生成一次 → 并排对比渐变区域（这一步在建造台里就能完成，不用进游戏）。再切「优先保色相」看人像肤色。

> 三个可选开关，/ 默认【全关】，/ 不影响原本的手感。
> 这个叫【抖动】，/ 处理渐变 —— 关掉会看到一条条色带，/ 打开就顺滑了。
> 这个是【优先保色相】，/ 专治"红变棕、蓝变紫"，/ 画人物的时候开它。

### 镜头 6｜1:35–1:55　自定义色卡

**画面**：打开色卡面板 → 在原图上点一下取色（特写取色的小色块）→ 选方块 → 添加 → 重新生成预览，指着那块被修正的区域。

> 如果某个区域怎么调都不对，/ 可以直接【指定】。
> 在图上点一下取色，/ 选一个方块，/ 加进去。
> 最多存五十条，/ 跟着工程一起保存。

### 镜头 7｜1:55–2:10　其它功能（快速过，别啰嗦）

**画面**：三四个快速切换：预处理（拖拽裁剪）→ 导出工程 → 断点续传提示框。每个 3~4 秒。

> 还有裁剪、旋转、亮度对比度，/ 自动缩放到你想要的大小。
> 工程可以存下来，/ 下次接着建。

### 镜头 8｜2:10–2:30　搭配推荐（**必须讲，不讲会被评论区骂**）

**画面**：先关掉 HEROsMod 全亮（画面明显发黑，停 2 秒）→ 再打开（亮起来）。然后 Better Zoom 拉一个远景。

> 最后说个【很重要】的事。
> 这个模组只负责放方块，/ 不管灯光，/ 也不管镜头。
> 所以强烈建议同时装【HEROsMod】和【Better Zoom】。
> 不开全亮的话 —— 你看 / 建出来的东西中间是黑的，/ 你自己都看不清建了啥。

### 镜头 9｜2:30–2:45　收尾

**画面**：成品远景 + 屏幕文字三行：`创意工坊：泰拉图像建造台` / `桌面端下载：见工坊描述` / `下期：复刻经典画面`。

> 创意工坊搜【泰拉图像建造台】，/ 免费订阅。
> 桌面端程序在工坊页面的描述里，/ 【国内网盘】和 GitHub 都有链接。
> 下期我拿它复刻几个经典画面，/ 感兴趣可以先订阅。

## 五、录音与字幕

**录音**：

1. 先录画面，剪完再配音 —— 边操作边录，鼠标声会全进去
2. 一段一条，念错就重念那一段（不要一气念完）
3. 话筒离嘴 15~20cm，侧 45°（避免喷气声）
4. OBS 音频滤镜加两个：**噪声音频抑制** + **限幅器**，够用了，不用买声卡

**字幕**（三条路，按省事程度排）：

| 方案 | 做法 | 适合 |
|---|---|---|
| 剪映 / CapCut | 导音频 → 自动识别字幕 → 改错别字 | 想当天出片 |
| faster-whisper | `pip install faster-whisper` → 转 SRT → 拖进剪辑软件 | 想时间轴精确 |
| Remotion | 字幕是一个数组，改一行就重渲染 | 想统一视觉风格 / 要反复改 |

**字幕规范**：一行 ≤ 18 个汉字、最多两行；专有名词统一写成 `HEROsMod`、`Better Zoom`、`CIEDE2000`；数字用阿拉伯数字。

**BGM**：音量压到人声的 -20dB 以下（几乎听不见但能填空白）。别用有版权争议的曲子。

## 六、封面 / 标题 / 简介

**封面（三选一，我建议第 2 个）**：

1. 成品像素画全景 + 大字`一张图 = 一面墙`
2. **左右对比**：左边原图、右边方块成品，中间一个大箭头 —— 信息量最大，点击率通常最高
3. 用本地模型生成氛围图（`python D:\deepseek\ds_gen.py image --prompt "..."`），但**别做成和游戏无关的插画**，会误导

**标题**（含搜索关键词）：

- 抖音：`把任意图片变成泰拉瑞亚像素画，只用一张图`
- B站：`【泰拉瑞亚】把图片自动变成方块像素画 · 模组介绍 + 实测 12 万方块`

**简介模板**：

```
模组：创意工坊搜索「泰拉图像建造台」（Terraria Image Builder）
桌面端下载：工坊页面描述里有网盘和 GitHub 链接（模组本身不含桌面程序）
推荐搭配：HEROsMod（全亮）、Better Zoom（镜头）

本视频演示：原图 → 自动匹配 42 种原版方块 → 分块建造 12 万方块
```

## 七、发布后的评论预案（提前写好，直接复制）

| 评论 | 回复 |
|---|---|
| 画面怎么这么黑 | 需要开 HEROsMod 的全亮模式，模组只管放方块，不管灯光 |
| 白色部分发灰 | 原版没有"亮中性且实心"的方块（雪和微光砖偏冷，珍珠沙会塌方），是色域限制 |
| 一直显示未连接 | 要先下载桌面端程序（工坊描述里有链接），模组只是执行器 |
| 会不会封号 / 违规 | 只用原版方块、不改游戏逻辑、不上传任何外部程序，符合工坊规则 |
| 能不能用于多人 | 可以，模组是客户端兼服务端，建造者需要桌面端 |
