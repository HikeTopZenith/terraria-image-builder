[b]把你的图片，变成泰拉瑞亚里的方块像素画。[/b]

导入一张图 → 自动匹配原版方块 → 分块发给游戏 → 站在原地看它自己长出来。

[b]【下载桌面端（必须）】[/b]
创意工坊只能分发模组本身。把图片算成方块、生成蓝图的桌面程序在这里（解压即用，无需安装 Python）：
https://github.com/HikeTopZenith/terraria-image-builder/releases/latest

[b]【核心能力】[/b]
· CIEDE2000 色差匹配：按人眼感知算色差，不是简单 RGB 比色；传统 LAB 算法可切换
· 贴图级色库：42 种原版方块的固有色直接从游戏贴图采样（剔除阴影与烘焙光照），不是手填的估算值
· 三项可选微调，默认全关：优先保色相（压掉「红变棕、蓝变紫」）/ 纯色方块优先 / Floyd–Steinberg 抖动
· 自定义色卡：顽固偏色区可手动指定「这个颜色 → 这个方块」，最多 50 条，随工程保存
· 离线预览：不连游戏也能看到方块化结果，与蓝图用同一套匹配逻辑，所见即所得
· 预处理：拖拽裁剪、旋转、镜像、亮度对比度、自动缩放到目标方块数
· 工程包 .tibp：蓝图与全部参数一起保存，旧工程完全兼容
· 断点续传：大图建到一半断线，重连后只补未完成的分块
· 安全：单次 20 万方块硬上限、坐标与方块 ID 全量校验、断线自动清队列、一键撤销全部

[b]【游戏内操作】[/b]
O 标记原点 · P 开始/暂停 · U 撤销全部（三个键都可以在 config.json 自定义）
4 档放置速度 + 自适应降速 + 自动避让玩家位置

[b]【推荐搭配】[/b]
本模组[b]只负责把图片变成方块[/b]。灯光与镜头请交给专业工具：
· HEROsMod（全亮模式 / 建造工具）
· Better Zoom（镜头缩放，远观像素画必备）

[b]【使用流程】[/b]
1. tModLoader 中启用本模组，进入世界
2. 运行外端建造台 → 点「连接游戏」（连上会显示「已连接 · 模组 vX.Y.Z」）
3. 导入图片 → 调参数 → 生成预览 → 开始建造
4. 想看清就开 HEROsMod 全亮，想远观就开 Better Zoom

[b]【English】[/b]
Turns your images into Terraria block pixel art. A companion desktop app (Windows, no Python needed) computes the blueprint; this mod only places the blocks.
· CIEDE2000 perceptual matching (legacy LAB selectable) · palette sampled from real vanilla tile textures
· Optional: hue-preserving / pure-block priority / Floyd-Steinberg dithering — all off by default
· Custom color-card rules (up to 50) · offline preview sharing the same matching path · .tibp project files
· Safety: 200k block hard cap, full coordinate/ID validation, queue cleared on disconnect, one-key undo
Hotkeys: O set origin, P start/pause, U undo all (rebindable in config.json).
Recommended companions: HEROsMod (fullbright / build tools) and Better Zoom (camera zoom).
Desktop app download: https://github.com/HikeTopZenith/terraria-image-builder/releases/latest
